digiemu 0.2.0 adds the **Digitone (mk1)**. It runs the Digitone's own firmware, which you supply, in a window of its own, including the second processor that plays the Digitone's FM voices. The Digitakt (mk1) works as before.

## Get started

1. Download **digiemu-win64-0.2.0.zip** below and unzip it anywhere you can write to, except a OneDrive folder.
2. Get the firmware from Elektron's website: `Digitone_and_Digitone_Keys_OS1.43.syx` for the Digitone, or `Digitakt_OS1.53.syx` for the Digitakt.
3. Run `digiemu.exe`, click **Add firmware** and pick the `.syx`. Setup runs once per firmware and takes about 25 seconds on a desktop.
4. Click **Play**.

The exe is not code-signed, so Windows SmartScreen asks first: choose *More info*, then *Run anyway*. A PC with Smart App Control turned on blocks it. Tested on Windows 11, 64-bit.

**Upgrading from 0.1.0:** unzip 0.2.0 into a new folder, then move the `firmware` folder from your 0.1.0 folder into it. A Digitakt set up with 0.1.0 opens where you left off, without being set up again.

## What's new

- **Digitone mk1 OS 1.43.** It boots to its live user interface, in a window with the Digitone's layout: the six parameter-page keys, T1–T4, and LEVEL/DATA beside the eight encoders. Every key, encoder and key LED works, and so do the sequencer and the +Drive.
- **The Digitone's FM voices are its own.** The Digitone renders them on a second processor. digiemu emulates that processor too, running the firmware's own voice code, live at 48 kHz. This takes most of a second CPU core.
- **Encoders respond sooner, on both products.** A mouse-wheel notch now turns a knob by four steps. The firmware's encoder driver has a dead zone, and before this a knob needed about 16 notches before anything moved.
- `digiemu-console.exe` sets up and lists the Digitone too (`--add`, `--list`, `--rebuild`, `--reset`).
- This is the first release built by GitHub Actions from its tag. See *Build* below.

## Known limits

- The Digitone runs as a plain Digitone. The Digitone Keys' keyboard, wheels and extra keys are not there.
- The Digitone has no sample engine, so its window has no LOAD SAMPLES.
- The Digitone has not been tried on a slow PC yet. It needs a second core for its voices.
- The Digitakt's factory *sample* library lives on the real device's storage, not in the firmware, so `/factory` is empty.
- Whether 44.1 kHz samples play at the right pitch is not verified yet.
- Only Digitone OS 1.43 and Digitakt OS 1.53 are tested. Other releases of the two run once you confirm; other Elektron products are recognised and turned away.
- Control Flow Guard is cleared in both exes, because Unicorn's `longjmp` fails under it. The process then has the same protections as `python.exe`.
